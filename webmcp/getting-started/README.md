# Syncfusion&reg; JavaScript (ES6) DOCX Editor (Document Editor) - WebMCP Getting Started

This sample demonstrates how to enable and configure the WebMCP (Model Context Protocol) support in the Syncfusion<sup style="font-size:70%">&reg;</sup> JavaScript (ES6) DOCX Editor (Document Editor) using the `DocumentEditorContainer` component with the Ribbon toolbar.

# Key Features

* Enables WebMCP support in the Document Editor Container using the `enableWebMcp` property, allowing AI agents to interact with the editor through the Model Context Protocol.
* Registers the editor as a WebMCP tool provider using the `webMcpSettings` property, so AI assistants (like Chrome's built-in AI agent) can discover and invoke document editing tools.
